# AGENTS GLOBAL GUIDELINES

## 1. Tech Stack & Architecture
- **Frontend:** Next.js 14 (App Router) / React / TailwindCSS.
- **Backend:** Python (Flask/FastAPI) hoặc Node.js tùy module.
- **Database:** SQLite / PostgreSQL với ORM chuẩn.

## 2. General Coding Standards
- Viết code sạch,modular, có comment giải thích logic phức tạp.
- **Tuyệt đối không** hardcode biến môi trường; luôn dùng file `.env`.
- **Commit Message:** Tuân thủ chuẩn Conventional Commits, viết bằng **tiếng Việt** hoặc tiếng Anh rõ nghĩa (Ví dụ: `feat(auth): thêm chức năng đăng nhập JWT`).
